Arklow splits the work going to a destination into lanes. When each user has their own lane, Arklow can balance one user's demand without slowing the others. It does this only when [**Admission control**](https://app.arklow.io/dashboard/settings?tab=organization) is on.

## Identity modes

| Mode | Lane identity | Use |
|---|---|---|
| **Complete tags** | The complete normalized tag map | The default when every tag combination should have independent control |
| **Partition tag** | One configured tag name and value | Stable customer, tenant, account, region, or workload scopes |

Tag order has no effect on identity. A run with no tags uses the destination's untagged lane.

## Set a partition tag

When the partition tag holds your user identifier, each user has their own lane. See [Isolate users](/fundamentals/isolation) for the steps.

## Partition behavior

### Missing values

Runs with a missing or empty partition value use the destination's shared untagged lane regardless of the other tags.

Choose a partition tag that is present on every run that requires isolation.

### Other tags

Tags outside the partition remain attached to the run and available to rules, metrics, and observability. The partition value alone determines the lane and its limits.

## Tag sources

Tags can come from:

- The `tags` field sent to [HTTP ingress](/resources/sources/arklow/ingress).
- `tag.<key>` query parameters on HTTP ingress.
- Source attributes configured to become tags.
- An [Assign Tags rule](/resources/rules/index#assign-tags).

## Cardinality

A destination can hold at most **50,000 lanes**. Ingress will accept the work, but raise the error `TAG_CARDINALITY_EXCEEDED`. New tags won't be recorded, and will default to the default destination.

Request identifiers, timestamps, and other unbounded values should stay outside lane identity. A partition tag can keep descriptive tags on the run while bounding lane identity to the selected values.

Arklow can always raise this limit on request, and exists to prevent unbounded lane generation.
