The Baseten target commands the replica count of a model's production deployment.

## Configuration

| Field | Value |
|---|---|
| **Model ID** | The Baseten model whose production deployment Arklow may observe and change. |
| **Credential** | An [HTTP Auth Headers credential](/resources/credentials/http/auth-headers). |
| **Minimum replicas** | The lowest replica count Arklow may command. The minimum can be `0`. |
| **Maximum replicas** | The highest replica count Arklow may command. |

The model ID is available in Baseten's model details and API URLs. Arklow uses the model's `production` deployment alias, so you do not need a deployment ID.

## Authentication

Create an HTTP Auth Headers credential with the header Baseten expects for its API key:

```text
Authorization: Api-Key <api-key>
```

Keep the key in the credential and enable Baseten under **Scale target providers**.

## Observations and changes

Arklow reads the production deployment's status and active replica count. A deployment in a transitional state, such as deploying or updating, is allowed to finish before another change is applied.

For a command of `1` or more, Arklow sets Baseten's minimum and maximum replicas to that value. For a zero command, Arklow uses Baseten's scale-to-zero shape: a minimum of `0` and a maximum of `1`.

The observed active replica count may take time to respond while Baseten provisions or removes replicas.

## Attach a Baseten target

<Steps>
  <Step title="Enable Baseten">
    Open the HTTP Auth Headers credential and enable **Baseten** under **Scale target providers**.
  </Step>
  <Step title="Sync the inventory">
    Click **Sync now** and open [**Scale Targets**](https://app.arklow.io/dashboard/scale-targets).
  </Step>
  <Step title="Choose the model">
    Select the model under **Provider inventory** and click **Attach**. Arklow targets its production deployment.
  </Step>
  <Step title="Select capacity">
    Choose the destinations served by this deployment, or an existing pool. Choosing destinations creates a new pool with those destinations as its members.
  </Step>
  <Step title="Set permission bounds">
    Enter the lowest and highest replica counts Arklow may command.
  </Step>
  <Step title="Attach">
    Attach the target and confirm that **Last observed** advances without a credential or deployment error.
  </Step>
</Steps>
