An HTTP Auth Headers credential stores headers Arklow can attach to supported HTTP destinations, or compatible HTTP scale targets.

## Add credentials to Arklow

<Steps>
  <Step title="Open the credentials page">
    Go to [**Credentials**](https://app.arklow.io/dashboard/credentials) and click **Create credential**.
  </Step>
  <Step title="Pick the type">
    Set **Credential Type** to **HTTP Auth Headers**.
  </Step>
  <Step title="Add the headers">
    Under **Authentication Headers**, add one row per header.
  </Step>
  <Step title="Save">
    Click **Create credential**.
  </Step>
</Steps>

## Header precedence

Credential headers overwrite destination headers when they share the same exact name and casing. Use consistent casing to avoid combining two values for what the receiver treats as one header. Keep sensitive values in the credential rather than the destination's ordinary header configuration.
