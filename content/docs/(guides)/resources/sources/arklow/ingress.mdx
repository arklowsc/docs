HTTP ingress lets your service send work to Arklow directly.

```
POST https://ingress.arklow.io/v1/ingress/{variant}
POST https://ingress.arklow.io/v1/ingress
```

You can choose to provide Arklow fields as query strings, or alongside your payload.

## Using Query Strings

Use this form when the system that sends the request cannot change the shape of its body.

```bash
curl -X POST "https://ingress.arklow.io/v1/ingress/orders.created?tag.region=eu" \
  -H "X-Arklow-Auth: $ARKLOW_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"order_id": "8471", "total": 129.50}'
```

Each `tag.<key>=<value>` query parameter adds a tag.

If the body is a JSON object with a `payload` field in the root, Arklow reads the body as the payload, as below.

## Using the Payload Body

```bash
curl -X POST "https://ingress.arklow.io/v1/ingress" \
  -H "X-Arklow-Auth: $ARKLOW_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"variant": "orders.created", "tags": {"region": "eu"}, "payload": {"order_id": "8471", "total": 129.50}}'
```
