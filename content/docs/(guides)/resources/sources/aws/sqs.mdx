The SQS source pulls work from an Amazon SQS queue.

## Credentials

Uses an [AWS credential](/resources/credentials/aws/access-keys).

## Add SQS to Arklow

<Steps>
  <Step title="Open the action flow">
    Open the action for this queue, select **Flow**, and click **Add source**.
  </Step>
  <Step title="Pick the type">
    Set **Source Type** to **AWS SQS**.
  </Step>
  <Step title="Configure the queue">
    Enter the **Queue URL** and select a **Region**.
  </Step>
  <Step title="Choose how attributes become tags">
    Leave **Read platform attributes as tags** enabled to allow Arklow to read Attributes as tags. Only Attributes of type `String` and `Number` become tags.
  </Step>
  <Step title="Select the credential">
    Under **Authentication**, select the AWS credential.
  </Step>
  <Step title="Save">
    Click **Create source**.
  </Step>
</Steps>

## Rules

Rules can read attributes at the metadata path `message_attributes.<name>.StringValue`.
