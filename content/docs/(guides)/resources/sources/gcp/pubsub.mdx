The Pub/Sub source pulls work from a Google Cloud Pub/Sub subscription.

## Credentials

Uses a [GCP Service Account credential](/resources/credentials/gcp/service-account).

## Add Pub/Sub to Arklow

<Steps>
  <Step title="Open the action flow">
    Open the action for this subscription, select **Flow**, and click **Add source**.
  </Step>
  <Step title="Pick the type">
    Set **Source Type** to **Google Pub/Sub**.
  </Step>
  <Step title="Configure the subscription">
    Enter the **Project ID** and **Subscription ID**.
  </Step>
  <Step title="Choose how attributes become tags">
    Leave **Read platform attributes as tags** enabled to allow Arklow to read Attributes as tags. Only Attributes of type `String` and `Number` become tags.
  </Step>
  <Step title="Select the credential">
    Under **Authentication**, select the GCP Service Account credential.
  </Step>
  <Step title="Save">
    Click **Create source**.
  </Step>
</Steps>

## Rules

Rules can read attributes at the metadata path `attributes.<name>`.
